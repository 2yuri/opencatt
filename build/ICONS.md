# OpenCatt icons

Made from `logo-source.png`, the boss's logo, traced to vector in Pencil (OpenCat.pen, board "OP-55 · OpenCatt icon set"; `logo.svg` is that vector mark). Every file here is exported from those frames.

| File | Where it's used | Made from |
| --- | --- | --- |
| `icon.png` (1024) | default app icon | macOS frame |
| `icon.icns` | macOS app, Dock, Finder | macOS frame, 16 to 1024 @1x/@2x |
| `icon.ico` | Windows app, Start menu, taskbar, installer | 16, 24, 32, 48 from the simplified cat; 64 and 256 from the Windows/Linux frame |
| `icons/NxN.png` (16 to 512) | Linux menus and launchers | 16 to 48 simplified, 64 and up full |
| `trayTemplate.png`, `@2x` | macOS menu bar (black and alpha only; macOS tints it) | tray silhouette |
| `tray.png`, `@2x`, `tray.ico` | Windows and Linux tray (colour, readable on dark and light panels) | simplified cat, no plate |
| `dmg-background.png`, `@2x` (660x400) | macOS installer window; app icon at (180, 210), Applications at (480, 210) | dmg frame |

The simplified cat (16 to 48 px) drops the whiskers and mouth so it stays readable in the taskbar and Start menu search.
